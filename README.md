# AIHC 新安江水文模型软件（AIHC-XAJ）

AIHC-XAJ 是 AIHC 开发的新安江（XAJ）水文模型桌面软件：中文界面的工程向导、多站面雨量（泰森多边形等）、子流域网络与河道汇流（Nash 单位线、马斯京根）、稳态预热、模拟与结果查看、SCE-UA 参数率定和残差误差模型，并提供命令行工具。
